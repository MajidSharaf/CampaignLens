About the project

What are people
saying about any topic
— and why?

CampaignLens is an NLP pipeline that scrapes YouTube comments, runs dual-model sentiment analysis, named entity recognition, and topic modelling, then serves two opposing AI chatbots grounded entirely in what real commenters wrote.

Pipeline

Dual-model sentiment (Vader + RoBERTa), named entity recognition, LDA topic modelling.

4
Embedding & storage
Comments vectorised via Ollama, stored in Weaviate. REBEL triplets loaded into Neo4j.

RAG chatbots
LangGraph routes queries to Weaviate hybrid search or Neo4j. DSPy generates grounded answers.
