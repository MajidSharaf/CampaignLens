Local deployment

Docker setup

CampaignLens runs as six Docker services. No cloud account needed — everything stays on your machine. Follow the steps below to bring the stack up.

Weaviate
:8080
Vector database storing embedded comments
Ollama
:11434
Local LLM runtime — serves qwen2.5 and embeddinggemma
Neo4j
:7474 / :7687
Knowledge graph for entity relationship queries
MLflow
:5001
Experiment tracking for router and chatbot runs
App
internal
Embedding pipeline — loads comments into Weaviate
Chatbot
:8000
FastAPI server — this interface
1
Prerequisites

Make sure Docker Desktop is running and you have Git installed.

terminal 
docker --version
git --version
2
Clone the repository

Clone CampaignLens and move into the project directory.

terminal 
git clone https://github.com/your-org/CampaignLens.git
cd CampaignLens
3
Create the environment file

Create a .env file inside Weaviate/ with the values below. Set a Neo4j password of your choice.

Weaviate/.env 
# Weaviate
WEAVIATE_HOST=weaviate
WEAVIATE_PORT=8080

# Ollama
OLLAMA_URL=http://ollama:11434
OLLAMA_MODEL=qwen2.5:0.5b
OLLAMA_EMBED_MODEL=embeddinggemma

# Neo4j
NEO4J_URI=bolt://neo4j:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=your-password-here

# YouTube API (rotate if previously exposed)
YOUTUBE_API_KEY=your-api-key-here
Do not commit .env to git. It is already listed in .gitignore.
4
Pull the Ollama models

After Ollama starts, pull both models the pipeline needs. The embedding model is pulled automatically by the app container, but you can pre-fetch here.

terminal 
# Run this after step 5 once ollama is up
docker exec ollama ollama pull qwen2.5:0.5b
docker exec ollama ollama pull embeddinggemma
5
Build and start the stack

Run this from the Weaviate/ directory. Docker will build both the app and chatbot images, then start all six services in the correct order.

terminal 
cd Weaviate
docker-compose up --build
First build takes 5–10 minutes. Subsequent starts are fast. The chatbot service waits for Weaviate and Neo4j to pass their health checks before starting.
6
Load mock data (optional, for testing)

If the pipeline hasn't run yet, insert sample comments into Weaviate so the chatbots have something to retrieve from.

terminal 
docker exec chatbot python mock_insert.py
Services at a glance
http://localhost:8000 — CampaignLens chatbot interface (this page)
http://localhost:8000/docs — FastAPI auto-generated API documentation
http://localhost:5001 — MLflow experiment tracking dashboard
http://localhost:7474 — Neo4j browser (username: neo4j)
http://localhost:8080 — Weaviate REST API
